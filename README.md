# SahamID - Analisa Saham Indonesia

Aplikasi analisa saham Indonesia yang profesional dan akurat.

## Fitur

- **Dashboard** - Ringkasan pasar, indeks, top movers, sentimen
- **Screener** - Filter saham berdasarkan kriteria teknikal & fundamental
- **Analisa Teknikal** - Chart candlestick, indikator, pattern recognition
- **Analisa Fundamental** - Laporan keuangan, rasio, valuasi
- **Signal & Alert** - Sinyal trading otomatis, custom alert
- **Portfolio** - Tracking investasi, profit/loss, alokasi
- **Watchlist** - Daftar pantau saham dengan catatan
- **Backtesting** - Simulasi strategi pada data historis
- **Berita & Sentimen** - Berita pasar, kalender, trending
- **Heatmap** - Visualisasi pergerakan pasar & sektoral
- **Pengaturan** - Konfigurasi profil, notifikasi, API

## Cara Menjalankan

Buka file `index.html` di browser.

Atau gunakan live server:

```bash
npx serve .
```

## Tech Stack

- HTML5 + Tailwind CSS (via CDN)
- Vanilla JavaScript (SPA pattern)
- Font Awesome Icons
- Google Fonts (Inter)
